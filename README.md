# Multigrid Poisson Solver

Geometric multigrid (V-cycle / W-cycle) solver for the 2D Poisson equation,
built on top of the dense-matrix Jacobi/Gauss-Seidel/SOR code from
Assignments 1-4. See `Multigrid_Assignment_Report.docx` for full methodology,
results, and discussion.

## Build

```
make
```

## Run

```
./multigrid
```

You'll get a menu:

- **[1] Legacy single-grid demo** — the original Assignment 1-4 dense-matrix
  Jacobi / Gauss-Seidel / SOR comparison (interactive: enter nx, ny,
  iterations, omega).
- **[2] Interactive multigrid solve** — choose the finest grid size
  (as an exponent k, grid = 2^k+1 nodes per side, e.g. k=6 -> 65x65),
  number of levels, smoother, omega, pre/post-smoothing sweeps, cycle
  type (V or W), tolerance, and max cycles. Prints the residual history,
  final error vs. the analytical solution, and the measured asymptotic
  convergence factor.
- **[3] Automatic benchmark suite** — no input required. Runs a full matrix
  of configurations (smoother x cycle type, grid-size sweep for the
  mesh-independence study, and a hierarchy-depth sweep), prints summary
  tables, and writes `results/mg_benchmark.csv`.

## Test problem

`-Laplacian(u) = 2 pi^2 sin(pi x) sin(pi y)` on the unit square with
`u = 0` on the boundary. Exact solution: `u(x,y) = sin(pi x) sin(pi y)`.
Used to verify both discretization accuracy (should be 2nd order) and
solver correctness (residual and error should both vanish).

## Files

| File | Role |
|---|---|
| `include/poisson.h`, `src/poisson.cpp` | Legacy dense Poisson matrix + exact/rhs (from Assignments 1-4, unchanged) |
| `include/smoothers.h`, `src/smoothers.cpp` | Legacy dense-matrix Jacobi/GS/SOR (from Assignments 1-4, unchanged) |
| `include/stencil.h`, `src/stencil.cpp` | Matrix-free 5-point stencil operator + all 4 smoothers, used by the multigrid engine |
| `include/multigrid.h`, `src/multigrid.cpp` | Full-weighting restriction, bilinear prolongation, recursive V/W-cycle, `MultigridSolver` |
| `src/main.cpp` | Menu-driven CLI |
| `results/mg_benchmark.csv` | Output of benchmark mode (regenerated by running option [3]) |
| `results/plots/*.png` | Plots generated from `mg_benchmark.csv` for the report |
